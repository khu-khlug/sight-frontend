# 기록 첨부 파일 보기

## 작업 개요

기록의 `...` 메뉴에 첨부 파일 보기를 추가한다. 본문에 드러나지 않은 첨부 파일까지 확인하고 내려받을 수 있게 하며, 백엔드 파일 아이디를 확인해 누수를 보고할 수 있게 한다.

## 사용자와 목표

기록을 보는 회원은 그 기록에 연결된 첨부 파일 전체를 본문과 별개로 확인할 수 있다. 서버는 본문을 읽지 않으므로 본문에 보이지 않는 첨부 파일이 있을 수 있고, 이를 발견하면 관리자에게 보고할 수 있다.

## 사용자 경험 계약

- 기록의 `...` 메뉴에 첨부 파일 아이콘을 추가한다. 누르면 기록 헤더 아래에 첨부 파일 영역이 펼쳐지고, 다시 누르면 접힌다.
- 첨부 파일은 좌우 스크롤로 나열한다. 각 항목은 파일명과 크기를 보여 주고 내려받을 수 있다.
- 이 영역에서는 첨부 파일을 삭제할 수 없다.
- 항목에 마우스를 올리면 백엔드 파일 아이디를 보여 준다.
- 첨부 파일이 없으면 빈 상태 안내를 보여 준다.

## 허용 및 제한 정책

정책 변경 없음

## 입력 및 복구

내려받기에 실패하면 실패를 알리고 다시 시도할 수 있다.

## 데이터 및 연동

별도 API 없이 기록 조회 응답의 `files`(`id`, `fileId`, `url`, `name`, `size`, `contentType`)를 그대로 쓴다.

## 사용자 보호 및 개인정보

변경 없음

## 접근성 및 사용 환경

첨부 파일 아이콘과 각 항목에 접근성 이름을 제공한다. 호버로만 보이는 백엔드 파일 아이디는 키보드 포커스에서도 확인할 수 있게 한다.

## 검증

사용자가 직접 브라우저에서 영역 펼치기·접기, 좌우 스크롤, 내려받기, 호버 시 아이디 표시, 첨부 파일이 없을 때의 표시를 확인한다. 요청에 따라 에이전트는 테스트와 브라우저 동작 확인을 수행하지 않는다.

## 비목표

첨부 파일 삭제, 누수 보고 기능 자체, 백엔드 구현.
