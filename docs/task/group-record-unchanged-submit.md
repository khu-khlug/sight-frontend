# 변경 없는 기록 수정 요청 생략

## 작업 개요

기록의 본문과 첨부 파일 연결이 바뀌지 않았으면 프런트엔드에서 수정 요청을 보내지 않는다. 변경 없는 저장으로 수정 일시·활동 로그·그룹 활동 상태가 갱신되는 일을 막는다. 프런트엔드 구현 대상은 `sight-frontend`다.

## 사용자와 목표

기록 작성자는 기존 기록을 열어 확인하거나 편집한 뒤 원래 내용으로 되돌렸을 때 불필요한 수정 이력을 남기지 않는다. 본문 또는 첨부를 바꾸면 저장할 수 있어야 한다.

## 사용자 경험 계약

- 기존 기록을 열어 아무것도 바꾸지 않았거나 본문과 첨부를 원래 상태로 되돌렸으면 기록 수정 요청을 보내지 않는다.
- 본문 또는 첨부 파일 연결이 바뀌었으면 저장한다. 본문이 같아도 첨부 추가·제거는 변경이다.
- 저장에 성공한 내용으로 다시 저장해도 추가 수정 요청을 보내지 않는다.
- 미완료 파일 업로드와 실패한 저장은 변경이 없는 상태로 취급하지 않으며, 재시도를 계속할 수 있어야 한다.

## 허용 및 제한 정책

### 변경 없는 기록의 수정 요청

- 주체: 기존 기록을 수정할 수 있는 작성자
- 조건: 마지막으로 저장에 성공한 기록과 본문·첨부 연결이 같고 미완료 저장이나 업로드가 없음
- 행동: 변경 없는 기록의 수정 요청 전송
- 판정: 금지
- 허용 예외: 없음
- 사용자에게 보이는 처리: 기록 수정 요청을 생략하고 기록 수정 일시와 활동 이력을 유지한다.
- 보장 계층: Frontend
- 안내 및 회복: 본문이나 첨부 연결을 변경하면 저장할 수 있다.

## 입력 및 복구

- 입력이 있었다는 사실만으로 변경을 판단하지 않는다. 입력 후 원래 상태로 되돌린 경우도 요청을 생략한다.
- 저장·업로드 실패 시 작성 내용과 첨부를 보존하고 재시도를 허용한다. 실패한 요청을 저장 완료 상태로 취급하지 않는다.
- 임시저장 복원 후에도 저장된 기록과 비교해 수정 요청 여부를 판단한다. 임시저장의 저장·복원·삭제 계약은 유지한다.

## 데이터 및 연동

- [기록 수정 API](../../../sight-spring-backend/docs/plans/group/edit-window/group-record-update.md)를 사용한다. 본문과 첨부 파일 연결이 변경 판단 대상이며 API의 요청·응답 필드는 유지한다.
- 백엔드는 `feat/group-record`에서 기존 본문의 동일 여부를 비교하지 않으며, 수정 요청이 성공하면 `updatedAt`·수정 로그·최근 활동 일시를 갱신하고 중단 그룹을 진행 중으로 전환한다. 같은 내용의 요청도 수정으로 처리한다.
- `sight-spring-backend`는 수정 요청을 처리하고 권한·본문·첨부의 유효성을 검증한다. `sight-frontend`는 변경이 없는 수정 요청을 생략한다. 이 태스크의 프런트엔드는 해당 백엔드 계약에 맞춰 연동한다.
- [기록 첨부 계약](../../../sight-spring-backend/docs/plans/group/global.md#기록-첨부-파일)을 따른다. 신규 첨부 업로드 후 본문·연결에 저장할 변경이 남으면 후속 수정을 수행하고, 변경이 없으면 추가 수정을 보내지 않는다.

## 사용자 보호 및 개인정보

변경 없는 저장을 막더라도 실패한 업로드나 저장의 재시도를 막거나 작성 내용·임시저장을 유실하지 않는다. 권한 검증은 기존 백엔드 계약을 따른다.

## 검증

사용자가 직접 브라우저의 요청 내역과 기록 표시를 확인한다.

- 기존 기록을 열어 저장하거나, 편집 후 원래 본문·첨부로 되돌려 저장하면 수정 요청이 없고 수정 시각·활동 이력이 유지된다.
- 본문만 변경하거나 첨부만 추가·제거하면 저장 요청이 발생하고 결과가 반영된다.
- 저장에 성공한 뒤 같은 상태로 다시 저장하면 추가 수정 요청이 없다.
- 임시저장을 복원했을 때 기록과 같으면 수정을 생략하고, 다르면 저장할 수 있다.
- 첨부 업로드나 후속 저장이 실패하면 입력을 유지한 채 재시도할 수 있고, 필요한 후속 저장을 마쳐야 저장 완료로 처리한다.

## 비목표

- 기록 작성·임시저장·권한 정책 변경
- 백엔드의 본문 비교나 해시 저장 도입
